Git

  • git init - создаёт новый репозиторий в текущей директории, создавая скрытую папку.
  • git status — показывает текущее состояние файлов в рабочем каталоге: неотслеживаемые, изменённые и подготовленные к коммиту файлы.
  • git clone — создаёт локальную копию удалённого репозитория.
  • git branch — позволяет создавать, удалять и перечислять ветки.
  • git pull — получает последние изменения из удалённого репозитория и объединяет их с локальным репозиторием.
